# Backend Wiki

A practical path from Ruby fundamentals to reliable Rails systems in
production.

This is a **learning reference**, not a framework glossary. Each page connects
an idea to a request, a database, a job, an operational concern, or a failure
mode.

## Start here

- [Follow the learning path](learning-path/index.md)
- [Choose a project](learning-path/projects.md)
- [Review self-check questions](questions.md)

## What this wiki covers

| Area | Outcome |
| --- | --- |
| Ruby | Write clear, testable programs and understand object behavior |
| Rails | Build APIs with explicit boundaries and useful defaults |
| Data | Model PostgreSQL data safely and reason about transactions |
| Operations | Deploy, observe, and debug backend services |
| Algorithms | Select practical algorithms for latency and scale |
| Postmortems | Turn incidents into durable engineering improvements |

## How to use it

Read the path in order for a curriculum, or use search when solving a
specific problem. Examples favor plain Ruby and Rails conventions over
abstractions that hide the underlying behavior.
